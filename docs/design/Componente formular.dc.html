Componente de formular

Un singur set de câmpuri pentru toată aplicația. Fiecare câmp din panouri, dialoguri, setări și bare de filtre se construiește din piesele de mai jos, cu aceleași valori. 25a anatomia și stările. 25b tipurile de câmp. 25c alegeri (bifă, radio, comutator, segmented, pastile, carduri). 25d suma mare și căutarea cu listă. 25e mărimea mică, pentru filtre și rânduri de setări. 25f un panou întreg construit doar din aceste piese.

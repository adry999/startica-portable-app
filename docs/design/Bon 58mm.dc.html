Cum se tipărește: în Achitări ⋯ → „Tipărește confirmarea” apare alegerea A4 · A5 · Bon 58 mm (implicit se ține minte ultima). La 58 mm, pagina are @page { size: 58mm auto; margin: 0 }, lățime 48 mm, fără culori (filter: grayscale(1) pe logo). Imprimanta SK58 se alege în Windows ca imprimantă implicită pentru bonuri. „Închiderea zilei” se tipărește din Dashboard, seara.
